- liton is a blank slate for working with AI agents. You build your own interface from widgets, and each widget binds to whatever capabilities your connected daemons advertise: chat, terminal, git, CI, tickets, rooms, review, the agent's environment. No single interface fits everyone. buzz-style rooms hide the code, and Paseo-style workspaces aren't social. liton ships sane presets and lets anyone rebuild them from the same parts.
- Everything is modular: providers (Paseo, GitHub, Nostr, sandboxes, ...) and widgets are Roc packages, the UI and daemon are separate, and a whole setup is a deterministic snapshot others can load.
- The UI is built with [roc-signals](https://github.com/lukewilliamboswell/roc-signals). The daemon and tooling are built in Roc, on the Zig-based compiler pinned in `.roc-version`.
- liton is provably faster than Paseo's own clients, not just as fast: it opens, shows an agent and reacts to a tap sooner, and asks less of the daemons it talks to. Benchmarks that run the same tasks against both, measuring load time, time to the first agent shown, input latency, memory, download size and the requests a daemon serves, are part of the repository and are rerun as liton changes, so the claim is checked rather than asserted.
